Live investigation

A smart greenhouse always reports 25°C even during an extremely hot afternoon.

Evidence log

  • ✓ Wi-Fi connection is active.
  • ✓ Dashboard updates every minute.
  • ✓ Cooling fan operates correctly when manually activated.
  • ✓ Temperature reading never changes.

Which IoT component is most likely faulty?

Engineering feedback

Sensors collect environmental information. Since every other component is functioning correctly but the temperature reading never changes, the temperature sensor is most likely faulty. Connectivity is working because updated data reaches the dashboard; the cloud displays information but does not measure temperature; the fan actuator works when manually activated.

The warehouse temperature is detected correctly. The dashboard shows accurate readings. However, the cooling fan never starts.

Evidence log

Temperature is being measured and displayed accurately, but the physical cooling action never occurs.

Which IoT component is responsible?

Engineering feedback

Sensors successfully detect temperature, and the accurate dashboard reading shows the information is moving through the system. The processor has already determined cooling is needed. An actuator performs physical actions, so because the fan never operates, the actuator is the faulty component.

Soil moisture is measured correctly. However, farmers cannot view the data remotely. The dashboard never updates.

Evidence log

The field device can take measurements, but no current measurement reaches the remote dashboard.

Which component is responsible?

Engineering feedback

Connectivity transfers data between devices and services. The sensor is functioning because measurements exist. Without communication, the cloud cannot receive information for the user interface to display. The failed link is connectivity.

A wearable device successfully records heart-rate readings. The readings reach the monitoring system. However, abnormal heart-rate alerts are never triggered.

Evidence log

Heart-rate data is collected and received, yet no decision or alert is produced from abnormal values.

Which component is responsible?

Engineering feedback

The processing unit analyses incoming data and compares readings against predefined thresholds. The wearable sensor is collecting data and the monitoring system receives it. If alerts are never generated despite abnormal readings, the processing unit is responsible.

Machines continue collecting production data. Operations continue normally. Managers working remotely cannot access historical production reports.

Evidence log

Production data is still collected locally, but historical records cannot be retrieved by remote managers.

Which component is responsible?

Engineering feedback

Cloud platforms store and manage data for remote access and historical analysis. Since production continues normally, data collection is functioning. The inability to retrieve historical records indicates a cloud platform issue.
